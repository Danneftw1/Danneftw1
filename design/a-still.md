# Direction A — Stilla

A proposal, not implemented. Canvas: https://claude.ai/artifact/2bVTHFQD4EcCCW2RUGGxD2
(boards "A · Stilla", 896 and 390 px, light and dark). Written 2026-10-05.

## What it is the opposite of

Today's page is dark, moving, dense and drawn: a condensed display face beside a mono face, a
machine rendered in text characters, four framed panels, one neon. Stilla is light, still, sparse
and written: one typeface at one size scale, no panels, no image, no animation, no accent. The
one mark is a 12 px square. The same facts, read in two minutes.

## Layout

- One column, `max-width: 62ch`. 896 px: padding 112 / 128 / 120; 390 px: padding 56 / 24 / 64.
- Sections separated by space only (56 px at 896, 40 px at 390): header, intro, Now, Record,
  Older. No rules, no boxes, no icons.
- Header: the square mark, the name at 44 px / 600 (34 px at 390), one grey line
  "AI engineer, full-stack. Göteborg."
- Section labels: 14 px, uppercase, 0.12 em tracking, grey. Project names in 600; everything
  else 400.
- Record and the stack are prose, two sentences. Older is one paragraph of links.

## Tokens

- Light: page `#ffffff`, ink `#1a1a1a`, grey `#5f5f5f`. Dark: page `#0d1117`, ink `#e6e6e3`,
  grey `#9a9a96`. No third colour.
- Type: Source Serif 4 (Google Fonts), optical size on, 400 and 600; 20 px / 1.6 at 896,
  18 px / 1.6 at 390.
- Links: ink, 1 px underline, 3 px offset; grey on hover.

## States

None. Nothing is interactive beyond links; nothing animates; reduced-motion changes nothing.

## What may never change

1. One typeface, one colour of ink, one grey. No accent anywhere.
2. No panel, frame, chip, tag, icon or image. The square is the only non-text element.
3. Nothing moves.
4. Every fact is the README's; nothing invented, no LinkedIn.
5. 390 px: no horizontal scroll, links ≥ 44 px tall tap targets by line height and spacing.

## If chosen

Implementation is `README.md` only: GitHub renders no fonts, so the typeface would come from
one static SVG for the header block (name + line + square) generated by `tools/build-assets.py`,
and the rest stays Markdown. The spec then moves to `design/full-version.md`'s place.
