I build LLM pipelines and the products around them: multi-stage prompts, parallel model calls and structured
output, the TypeScript and Python services that run them, and the Azure infrastructure underneath. I work as an
innovation developer at Quokka, a consultancy in Gothenburg, Sweden. My background is in AI and machine learning,
which I studied at IT-högskolan. Most of my work lives in private repositories.

I have played and recorded drums since about 2009.

**Stack:** TypeScript, Python, React, Express, Flask, Azure OpenAI, Microsoft Foundry, Bicep, GitHub Actions,
Langfuse, Claude Code.

## Private side projects
